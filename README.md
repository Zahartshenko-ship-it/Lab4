# Задание 1

## List

### Текст задачи

Составить программу, которая удаляет из списка L за каждым вхождением элемента Е один элемент, если такой есть, и он отличен от Е.

### Алгоритм решения

В классе `ListTask` реализован обобщённый метод `RemoveElementAfterTarget<T>(List<T> list, T targetElement)`.

- Выполняется проверка на `null` и пустоту списка для раннего выхода.
- Метод производит обход списка с помощью цикла `for`.
- При нахождении элемента, равного `targetElement` (сравнение выполняется через `EqualityComparer<T>.Default.Equals`), вычисляется индекс следующего элемента (`nextIndex = i + 1`).
- Если следующий элемент существует в границах списка и не равен `targetElement`, он удаляется методом `list.RemoveAt(nextIndex)`, а счётчик `_processedCount` увеличивается.
- В `Program.cs` считывание и вывод списка выполняются через обобщённые методы `ReadList<T>` и `PrintList<T>`.

# Задание 2

## LinkedList

### Текст задачи

Определить, есть ли в списке L хотя бы один элемент, который равен следующему за ним (по кругу) элементу (первый элемент считать следующим для последнего).

### Алгоритм решения

В классе `ListTask` реализован обобщённый метод `HasElementEqualToNextCircular<T>(List<T> list)`.

- Выполняется проверка на `null` и пустоту списка; при пустом списке возвращается `false`.
- В цикле `for` перебираются индексы элементов списка от `0` до `list.Count - 1`.
- Индекс следующего элемента по кругу вычисляется по формуле `(i + 1) % list.Count` (для последнего элемента следующим становится элемент с индексом `0`).
- Сравнение текущего и следующего элементов выполняется через `EqualityComparer<T>.Default.Equals(list[i], list[nextIndex])`. При совпадении метод возвращает `true`, если совпадений нет — `false`.
- В `Program.cs` для ввода и вывода списка используются универсальные методы `ReadList<T>` и `PrintList<T>`.

# Задание 3

## HashSet

### Текст задачи

Есть перечень стран, популярных у туристов. Определить для каждой страны, какие из них посетили все n туристов, какие - некоторые из туристов, и какие - никто из туристов.

### Алгоритм решения

В классе `ListTask` реализован метод `AnalyzeTourismChoices`, решающий задачу с помощью операций над множествами (`HashSet<int>`):

* **Страны, посещенные всеми (`visitedByAll`)**: инициализируются множеством первого туриста, после чего последовательно применяется операция пересечения (`IntersectWith`) с множествами остальных туристов.

* **Страны, посещенные некоторыми (`visitedBySome`)**: вычисляются путем объединения (`UnionWith`) всех множеств туристов.

* **Страны, которые не посетил никто (`visitedByNone`)**: формируются из полного диапазона стран от 1 до 100 путем вычитания (`ExceptWith`) множества стран, посещенных хотя бы одним туристом.

* В результирующий упорядоченный набор (`SortedSet<int>`) заносятся коды тех букв, для которых количество уникальных слов не равно 1.

# Задание 5

## Dictionary/SortedList

### Текст задачи

В некотором вузе абитуриенты проходят предварительное тестирование, по результатам которого могут быть допущены к сдаче вступительных экзаменов в первом потоке. Тестирование проводится по двум предметам, по каждому предмету абитуриент может набрать от 0 до 100 баллов. При этом к сдаче экзаменов в первом потоке допускаются абитуриенты, набравшие по результатам тестирования не менее 30 баллов по каждому из двух предметов. На вход программы подаются сведения о результатах предварительного тестирования. Известно, что общее количество участников тестирования не превосходит 500.

В первой строке вводится количество абитуриентов, принимавших участие в тестировании, N. Далее следуют N строк, имеющих следующий формат:
`<Фамилия> <Имя> <Баллы>`

Здесь `<Фамилия>` — строка, состоящая не более чем из 20 символов; `<Имя>` — строка, состоящая не более чем из 15 символов; `<Баллы>` — строка, содержащая два целых числа, разделенных пробелом, соответствующих баллам, полученным на тестировании по каждому из двух предметов. При этом `<Фамилия>` и `<Имя>`, `<Имя>` и `<Баллы>` разделены одним пробелом.
Примеры входных строк:
Ветров Роман 68 59
Анисимова Екатерина 64 88

Напишите программу, которая будет выводить на экран фамилии и имена абитуриентов, потерпевших неудачу, то есть не допущенных к сдаче экзаменов в первом потоке. При этом фамилии должны выводиться в алфавитном порядке.

### Алгоритм решения

## Решение разделено на два этапа: подготовка данных (ввод и запись в файл) и их обработка.
Ввод и валидация данных
* Пользователь вводит количество абитуриентов (N). Программа проверяет, чтобы N было в диапазоне от 1 до 500.
* В цикле считываются строки формата <Фамилия> <Имя> <Балл1> <Балл2>.
* Для каждой строки выполняется строгая валидация: проверяется количество введенных слов (ровно 4), длина фамилии (не более 20 символов) и имени (не более 15), а также корректность баллов (целые числа от 0 до 100).
* Если данные корректны, они сохраняются в массив, который затем записывается в текстовый файл applicants.txt.

Анализ данных 
* Метод принимает массив строк, прочитанных из файла, и выходной параметр типа SortedSet<string>.
* Каждая строка разбивается по пробелам. Фамилия и имя сохраняются, а баллы парсятся с помощью int.TryParse.
* Проверяется условие недопуска: если хотя бы один балл меньше 30 (score1 < 30 || score2 < 30).
* Если условие выполняется, формируется строка "Фамилия Имя". Данные добавляются в коллекцию SortedSet. Выбор этой структуры данных автоматически обеспечивает фильтрацию дубликатов и сортировку недопущенных абитуриентов в алфавитном порядке.

В методе RunTask5 происходит перебор элементов коллекции и вывод отсортированных данных на экран.

# Задание 6

## Перегрузка операций

### Текст задачи

Вычислить площадь треугольника. Результат должен быть типа double.

### Алгоритм решения

## Создание класса RightTriangle:
* Объявлены приватные поля _a и _b типа double.
* Написаны свойства A и B. В блоке set реализована валидация: если передаваемое значение <= 0, выбрасывается исключение ArgumentException с соответствующим сообщением. Это гарантирует инкапсуляцию и защиту состояния объекта.
* Метод CalculateArea() возвращает значение по формуле площади прямоугольного треугольника: 0.5 · a · b.
* Метод ToString() переопределен с использованием интерполяции строк для удобного и понятного вывода состояния объекта.
## Работа в Program.cs (RunTask6):
* Длины катетов считываются с консоли через вспомогательный метод ReadPositiveDouble, который запрашивает ввод до тех пор, пока пользователь не введет корректное положительное вещественное число типа double.
* Создание экземпляра RightTriangle обернуто в блок try-catch. Если бы валидация внутри класса не прошла, программа перехватила бы ArgumentException и вывела сообщение об ошибке, не допуская аварийного завершения (хотя базовая защита от дурака уже есть на этапе ввода).
* После успешного создания объекта на экран выводится информация о нем с помощью неявного вызова ToString() и вычисленная площадь.
