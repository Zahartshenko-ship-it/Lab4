# Задание 1

## List

### Текст задачи

Составить программу, которая удаляет из списка L за каждым вхождением элемента Е один элемент, если такой есть, и он отличен от Е.

### Алгоритм решения

В классе `ListTask` реализован метод `RemoveElementAfterTarget(List<int> list, int targetElement)`.

* Метод производит обход списка с помощью цикла `for`.

* При нахождении элемента, равного `targetElement`, вычисляется индекс следующего за ним элемента (`nextIndex = i + 1`).

* Если следующий элемент существует в границах списка и не равен `targetElement`, он удаляется с помощью метода `list.RemoveAt(nextIndex)`, а счетчик обработанных элементов `_processedCount` увеличивается.

# Задание 2

## LinkedList

### Текст задачи

Определить, есть ли в списке L хотя бы один элемент, который равен следующему за ним (по кругу) элементу (первый элемент считать следующим для последнего).

### Алгоритм решения

В классе `ListTask` реализован метод `HasElementEqualToNextCircular(LinkedList<int> list)`.

* Выполняется последовательный обход узлов связного списка (`LinkedListNode<int>`).

* Для каждого текущего узла определяется следующий узел: если `currentNode.Next` не равен `null`, используется он; в противном случае берется первый элемент списка (`list.First`).

* Сравниваются значения текущего и следующего элементов (`currentNode.Value == nextNode!.Value`). При их совпадении метод возвращает `true`.

# Задание 3

## HashSet

### Текст задачи

Есть перечень стран, популярных у туристов. Определить для каждой страны, какие из них посетили все n туристов, какие - некоторые из туристов, и какие - никто из туристов.

### Алгоритм решения

В классе `ListTask` реализован метод `AnalyzeTourismChoices`, решающий задачу с помощью операций над множествами (`HashSet<int>`):

* **Страны, посещенные всеми (`visitedByAll`)**: инициализируются множеством первого туриста, после чего последовательно применяется операция пересечения (`IntersectWith`) с множествами остальных туристов.

* **Страны, посещенные некоторыми (`visitedBySome`)**: вычисляются путем объединения (`UnionWith`) всех множеств туристов.

* **Страны, которые не посетил никто (`visitedByNone`)**: формируются из полного диапазона стран от 1 до 100 путем вычитания (`ExceptWith`) множества стран, посещенных хотя бы одним туристом.

# Задание 5

## Dictionary/SortedList

### Текст задачи

В некотором вузе абитуриенты проходят предварительное тестирование, по результатам которого могут быть допущены к сдаче вступительных экзаменов в первом потоке. Тестирование проводится по двум предметам, по каждому предмету абитуриент может набрать от 0 до 100 баллов. При этом к сдаче экзаменов в первом потоке допускаются абитуриенты, набравшие по результатам тестирования не менее 30 баллов по каждому из двух предметов. На вход программы подаются сведения о результатах предварительного тестирования. Известно, что общее количество участников тестирования не превосходит 500.

В первой строке вводится количество абитуриентов, принимавших участие в тестировании, N. Далее следуют N строк, имеющих следующий формат:
`<Фамилия> <Имя> <Баллы>`

Здесь `<Фамилия>` — строка, состоящая не более чем из 20 символов; `<Имя>` — строка, состоящая не более чем из 15 символов; `<Баллы>` — строка, содержащая два целых числа, разделенных пробелом, соответствующих баллам, полученным на тестировании по каждому из двух предметов. При этом `<Фамилия>` и `<Имя>`, `<Имя>` и `<Баллы>` разделены одним пробелом.
Примеры входных строк:
Ветров Роман 68 59
Анисимова Екатерина 64 88

Напишите программу, которая будет выводить на экран фамилии и имена абитуриентов, потерпевших неудачу, то есть не допущенных к сдаче экзаменов в первом потоке. При этом фамилии должны выводиться в алфавитном порядке.

### Алгоритм решения

В классе `ListTask` реализован статический метод `AnalyzeApplicants`:

* Каждая строка входного массива разбивается по пробелам на 4 составляющие: фамилию, имя и два балла. Выполняется валидация формата строки, успешности парсинга чисел (`int.TryParse`) и попадания оценок в допустимый диапазон от 0 до 100.
* Проверяется условие недопуска к экзаменам: если хотя бы один из двух баллов меньше проходного порога (`score1 < 30 || score2 < 30`), формируется ключ вида `"Фамилия Имя"`.
* Запись добавляется в коллекцию `SortedDictionary<string, string> failedApplicants` (с проверкой отсутствия дубликатов через `ContainsKey`). Использование `SortedDictionary` обеспечивает автоматическую лексикографическую сортировку абитуриентов по фамилии и имени.
* Вспомогательные методы в классе `Program` организуют пошаговый консольный ввод с повторным запросом при обнаружении некорректных данных.
